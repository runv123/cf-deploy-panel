CLOUDFLARE DEPLOYER

云端部署器

通用 Cloudflare 部署面板 · 一键把任意项目部署到 Workers / Pages， 并按需绑定 KV、D1、R2、Queues、Durable Objects、Vectorize、Workflows、Hyperdrive 等免费服务。

登录 Cloudflare

只需要邮箱 + Global API Key。前端不持久化密钥。

部署目标

选择部署到 Cloudflare Workers 还是 Pages，以及操作模式。

选择 .zip 压缩包即可一键部署；不选则拉取远程默认源。含 _worker.js 时作为高级模式脚本提交。

服务配置

勾选要绑定的 Cloudflare 免费服务，展开配置绑定名与新建/复用。

域名绑定（可选）

绑定自定义子域名；不填则用默认 *.pages.dev 或 *.workers.dev。
